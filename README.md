# Math Lab

A personal repository for exploring mathematics through reasoning, computation, simulation, visualization, and connections to statistics and machine learning.

The purpose of this repository is not simply to collect formulas or completed solutions. I use it to document how I move from a question or confusion to a deeper mathematical understanding.

## About This Repository

I created this repository to strengthen my understanding of mathematics, statistics, and related computational ideas.

Rather than starting from formulas and memorizing them, I try to begin with a question such as:

- Why does this formula work?
- What does this quantity actually represent?
- What changes when an assumption changes?
- How can I verify this idea with Python?
- How is this concept connected to statistics or machine learning?

Some questions may be very basic. I include them intentionally because identifying exactly what I do not understand is an important part of the learning process.

## Learning Approach

For each exploration, I try to follow a process like this:

**Question → Intuition → Theory → Hand Calculation → Python → Simulation → Visualization → Interpretation**

Depending on the topic, not every step will always be necessary.

My general approach is to:

- start with a specific question;
- explain my initial intuition;
- understand the mathematical reasoning behind the idea;
- work through a small example by hand;
- reproduce the idea with Python when useful;
- compare theoretical results with simulations;
- use visualizations to build intuition;
- connect the concept to statistics, machine learning, data science, or other applications when relevant;
- summarize what I learned in my own words.

The main goal is to understand why something works rather than only knowing how to use a formula or library.

## Repository Structure

This repository intentionally begins with a minimal structure.

I do not organize topics into categories such as mathematics, probability, statistics, or machine learning in advance. New notebooks, folders, and reusable code are added only when they become useful.
